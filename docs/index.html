📱 客户端下载

装哪个？ 手机就下 APK，电脑就下 安装程序 —— 都是点开就能装，不用解压。

安卓：下载完点开 apk，系统提示「未知来源」时选允许即可；装完桌面会出现「枪战突击」。
电脑：双击安装程序 → 选个目录 → 自动建桌面快捷方式；装完双击图标进游戏。

想联机？ 装好后在游戏里点「多人游戏」，填服务器地址（IP:8765 或朋友给的域名）。
不想装东西、只想在浏览器里玩？下上面的 绿色版，解压后双击 枪战突击.exe 或直接打开 index.html。

🧩 模组

📤 模组投稿（所有人都能投）

怎么投？ 填好上面 → 点「📮 去 GitHub 投稿」→ 会给你的浏览器开一条**已经写好内容的 GitHub 新建 Issue 页** （标题和代码都填好了）→ 直接点 **Submit new issue**。

没有 GitHub 账号？ 点「⬇ 下载成 .js」，把文件发给服务器主/群主，让他手动放进 docs/模组/。

投完会怎样？ 机器人会自动检查（格式、体积、危险代码），通过后**几秒内**就出现在「🧩 模组」页； 不通过会在这条 Issue 下面写原因，改完直接编辑那条 Issue 就会重新检查，不用重投。

不能做这些（会被直接驳回）：读 document.cookie、清 localStorage、 删 indexedDB、用 eval / new Function 动态执行代码、用 XMLHttpRequest 偷偷发数据、 把玩家 window.location 跳到别的网站。

写模组卡住了？ 版本包里带 mode/模组/模组开发教程.md（14 章，含完整模板）； 接口总表在「ℹ️ 说明」页下方。

ℹ️ 说明

这是什么？ 这里是《枪战突击》的版本与模组分发中心。每个版本独立打包，互不影响； 模组是玩家自己往游戏 mode/模组/ 目录里放的扩展（新英雄 / 新枪 / 新地图）。

怎么用？ ① 只想玩 → 到「📱 客户端」页下 安卓 APK（手机）或 电脑安装程序（Windows），装完就能进； ② 喜欢绿色版 → 到「📦 版本」页下 zip，解压后双击 枪战突击.exe，或者浏览器打开 index.html 即玩； ③ 联机再单独跑 服务端.js（或连朋友的服务器）。

模组放哪？ 下载的 .js 模组丢进对应版本目录下的 mode/模组/ 即可生效（启动器会帮你放）。

版本要求？ 模组卡片上的「接口 v2（需 1.7.5+）」表示它用的是 1.7.5 起的统一接口 枪战模组； 老版本（1.7.0）请下「通用」模组。版本包里的 mode/模组/模组开发教程.md 是完整教程。

旧版本？ 1.7.0 的版本包一直留在这儿，不会因为出新版就删掉。

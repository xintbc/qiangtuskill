# 🔫 枪战突击（QiangTu Strike）

> **⚠️ 本项目由 AI（人工智能）全程创作生成，包括代码、美术流程与文档。**
> **This project was entirely created by AI — code, assets pipeline and documentation.**

一款基于 **Three.js / WebGL** 的网页 3D 枪战游戏：MMD 角色 + HTJ 枪械模型，
波次防守 / 剧情营救 / 局域网多人对战，带英雄技能、模组系统、文字与语音聊天、
自定义闪光特效 / 背景 / 主菜单音乐。**打开网页即玩**，电脑客户端与安卓 App 均可离线运行。

当前版本：**v1.7.6**（语义化版本：大版本·大更新·小更新，服务器会校验版本）

- 🌐 发布中心（下载版本包 / 模组）：https://xintbc.github.io/qiangtuskill/
- 📦 旧版本存档：1.7.0 的完整快照留在仓库外（发布中心里 1.7.0 仍然可下载）

## 🚀 快速开始

### 方式一：单文件版（最简单，推荐先试）
双击 `网页3D枪战游戏.html` —— 全部游戏内容都在这一个文件里，无需服务器、无需构建。

### 方式二：多文件版（开发 / 模组用）
```bash
# 任选一个静态服务器（模组要用，file:// 下模组功能受限）
cd 多文件版
python -m http.server 8080        # 或 npx serve
# 浏览器打开 http://localhost:8080
```

### 方式三：多人联机
```bash
node 多文件版/服务端.js 8765        # 启动服务器（黑窗口保持开着）
# 局域网朋友浏览器打开  http://<你的IP>:8765/play  即可加入
```
> 服务端支持 Tailscale 永久隧道（`启动永久隧道.bat`），公网固定网址联机。
> 服务器会校验客户端版本（大版本一致且不低于服务器下限才能进）。

### 电脑客户端 / 安卓 App
- **客户端**：`多文件版/客户端/` 是纯 C + WebView2 源码，`打包安装包.py` 生成单文件安装程序
- **安卓**：`多文件版/手机版安卓/` 是原生壳工程，按 `① 准备资源 → ③ 一键打包` 出 APK
- 编译前的资源准备脚本会把网页本体复制进去（仓库里不含拷贝，保持精简）

## 🧩 模组开发

把 `.js` 文件放进 `mode/模组/`，在 `载入清单.js` 里写一行就生效（面板：设置 → 🧩）。

```js
/* 【模组信息】@id hello　@name 你好模组　@ver 1.0.0　@api 2 */
(function () {
  var M = window.枪战模组;              // 1.7.5 起的统一接口
  if (!M) return;
  var 我的 = M.定义({ id:'hello', name:'你好模组', ver:'1.0.0' });
  我的.加英雄({ /* … */ });              // 加武器/加刀/加地图/加技能/加模式…
})();
```

- **统一接口**：`window.枪战模组`（中文方法，一张表覆盖英雄 / 技能 / 枪 / 刀 / 投掷物 /
  地图 / 出生点 / 爆能器点位 / 敌人 / 模式 / 剧情 / 美术 / 物理 / 每帧 / 清场 / 联机广播）；
  老的 `ModLoader.addHero(...)` 等英文接口**全部保留**，老模组不用改。
- **教程**：`多文件版/mode/模组/模组开发教程.md`（14 章，一张接口总表 + 三个实战 + 完整模板）。
- **兼容**：文件头 `@api` 声明按哪版接口写；比游戏高的会标红并跳过，低的一律放行。
  `@ver` 是你的模组版本，只影响面板显示与发布中心标注。

## 🔧 版本号规则（v1.7.6）

- `major`：架构级改动（联机协议 / 存档格式）→ 大版本
- `minor`：一次大更新（新功能）→ 例：聊天语音、自定义资产、统一模组接口
- `patch`：小修小调 → 每次 +1

版本号定义在 `多文件版/js/02_状态键位与粒子.js` 的 `GAME_VER` 与 `服务端.js` 的
`SRV_VER / SRV_VER_MIN`。

## 🛠 技术栈

- 前端：Three.js（WebGL）、原生 JS 分片架构、Web Audio API
- 联机：Node.js 内置模块手写 WebSocket 协议（含二进制语音帧转发）
- 电脑端：C（Win32 + WebView2 虚拟主机）
- 手机端：Android WebView + aapt2/d8/apksigner 手工打包链

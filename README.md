# 枪战 3D（网页 3D 多人射击 Demo）

> 一个跑在浏览器里的 3D 多人在线射击 Demo：Three.js / WebGL 渲染，零依赖 Node 服务端，
> 支持电脑网页、手机网页、Windows 客户端、安卓 App 四种入口，可以自己开服联机。

## 这是什么

| 能力 | 说明 |
|---|---|
| 3D 渲染 | Three.js r128，程序化生成的地图 / 贴图，不依赖外部图片 |
| 玩法 | 团队死斗、波次生存、剧情模式、英雄技能（多位英雄 × 3 技能） |
| 联机 | WebSocket 自建服务器，房间 / 阵营 / 队伍 / 好友 / 在线列表，服务端权威判定 |
| 多端 | 电脑网页、手机网页（横屏触控）、Windows 客户端（WebView2）、安卓 App |
| 模组 | `window.枪战模组.定义()` 接口，热插拔，玩家可自装模组 |
| 其他 | 枪械改装、枪皮、载具、节日活动、月球基地地图等 |

## 快速开始

**只想玩**：直接双击 `网页3D枪战游戏.html`（单文件版，双击即玩，无需服务器）。

**想联机**：

```bash
# 1) 起服务器（纯 Node，零依赖，不用 npm install）
cd 多文件版
node 服务端.js 8765

# 2) 浏览器打开（同一局域网内任何设备都可以）
http://<你的内网IP>:8765/
```

公网部署：`多文件版/云端部署/` 是一份完整的服务器，丢到 Render / Railway 之类的平台即可，
详见 `云端部署/部署说明.md`。

## 目录结构

```
网页3D枪战游戏.html      单文件版（所有 js/css 内联，双击即玩）
多文件版/                开发用工程（分片 js，便于维护）
├─ index.html            页面骨架（布局 / CSS / 操作层）
├─ js/00~73_*.js         逻辑分片，按编号顺序加载
├─ 服务端.js             零依赖 Node 联机服务端
├─ mode/                 模组加载器 + 模组目录
├─ 客户端/               Windows 客户端（WebView2 壳 + 安装器源码）
├─ 手机版安卓/           安卓工程（WebView 壳）
└─ 云端部署/             云端服务器独立副本（cloud 分支）
```

> `多文件版/js/*.js` 是**唯一源**，`网页3D枪战游戏.html` 由工具从分片反向拼装，不要两头手改。

## 模组

在 `多文件版/mode/模组/载入清单.js` 里列出文件名，模组文件里写：

```js
window.枪战模组.定义({
  id: '我的模组', name: '我的模组', ver: '1.0.0',
  init: function () { /* 在这里加英雄 / 地图 / 武器 / 皮肤 */ }
});
```

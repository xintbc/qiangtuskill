# 模组开发教程 · 1.7.5（统一接口版）

> **一句话**：模组 = 一个 `.js` 文件，丢进 `mode/模组/`，在 `载入清单.js` 里写一行文件名，刷新页面。

## 1. 三条铁律

1. **不改引擎文件**，只写自己的 `.js`。升级会覆盖 `js/`、`index.html`；你的模组在 `mode/模组/` 里不会被碰。
2. **一切从 `枪战模组.定义()` 开始**。它登记你的名字/版本，之后登记的内容都记在你名下（面板里看得见）。
3. **文件头写一行模组信息**，管理器靠它显示版本、判兼容：

```js
/* 【模组信息】@id mymod　@name 我的模组　@ver 1.0.0　@api 2 */
```

`@id` 唯一标识（英文 + 下划线）·`@name` 显示名·`@ver` 你的模组版本·`@api` 按哪版接口写的（当前 2）。

## 2. 五分钟：最小可跑模组

**第一步，新建 `mode/模组/你好模组.js`：**

```js
/* 【模组信息】@id hello　@name 你好模组　@ver 1.0.0　@api 2 */
(function () {
  'use strict';
  var M = window.枪战模组;
  if (!M) { console.warn('[你好模组] 需要游戏 1.7.5 或更新版本'); return; }

  var 我的 = M.定义({ id: 'hello', name: '你好模组', ver: '1.0.0', author: '你', desc: '一句话说明' });
  if (!我的) return;

  我的.载入后(function () {
    我的.日志('全部模组载入完毕，可以开工了');
    if (typeof showMsg === 'function') showMsg('你好，模组已生效', '#9ff0d0');
  });
})();
```

**第二步，在 `mode/模组/载入清单.js` 里加一行**（不用写 `.js`，按数组顺序加载）：

```js
window.MOD_FILES = [
  '角色_魅影',
  '角色_暗影',
  '角色_夜莺',
  '示例_枪械包',
  '爪刀',
  '武器_暗影脉冲',
  '你好模组',      // ← 加这一行
];
```

**第三步，刷新页面**。控制台出现 `[模组加载器] 模组已登记：你好模组 …` 就成功了。

> 想确认到底加载了什么：控制台敲 `枪战模组.报告()`。

## 3. 目录、清单、模组面板

```
多文件版/
├─ index.html                 入口
├─ js/                        引擎分片（别改）
└─ mode/
   ├─ 模组加载器.js            引擎的加载器（别改）
   └─ 模组/
      ├─ 载入清单.js           ← 只改这里
      ├─ 角色_夜莺.js          官方示例（英雄）
      ├─ 示例_枪械包.js        官方示例（枪）
      ├─ 示例_接口演示.js      官方示例（全家桶）
      └─ 你的模组.js
```

**装 / 停 / 删**：游戏里 `设置 → 🧩 模组管理`。面板显示每个模组的版本与接口版本；`@api` 比游戏高的会标红并**不加载**（防止用新接口的模组把老版本跑崩）。

- 电脑客户端 / 手机 App：面板里能装、启停、删；
- 网页版（连服务器的）：**只读** —— 服务器上的模组由服务器主统一管理，放进 `mode/模组/` 全体同步；
- 没连服务器的网页（双击 html）：模组存在浏览器本地库（IndexedDB）。

## 4. 统一接口总表

```js
var 我的 = 枪战模组.定义({ id, name, ver, author, desc, api });
```

`定义()` 返回**属于这个模组的句柄**，下面所有方法都挂在它上面：

| 方法 | 作用 | 老名字（还能用） |
|---|---|---|
| `加英雄(hero)` | 加一个可选英雄 | `addHero` |
| `加技能(键, 函数)` | 注册一个自定义技能实现 | `addSkill` |
| `加武器(def)` | 加一把枪（返回槽位号） | `addWeapon` |
| `加刀(def)` | 加一把近战刀 | `addKnife` |
| `加投掷物(def)` | 加一种手持投掷物模型 | `addThrowable` |
| `加地图(map)` | 加一张图 | `addMap` |
| `加出生点(图id, 点位)` | 补出生点（自动进 `MAP_SPAWNS`） | `addSpawn` |
| `加爆能器地图(图id, 配置)` | 声明这张图能玩爆能器 | `addSpikeMap` |
| `加敌人类型(键, def)` | 加一种 AI 敌人 | `addEnemyType` |
| `加模式(def)` | 加一种玩法 | `addGameMode` |
| `加多人模式(def)` | 同上 + 队伍/分房标记 | `addMPMode` |
| `加剧情(章)` | 加一个剧情章节 | `addStory` |
| `加模型(名, 函数)` | 登记具名模型构建器 | `addModel` |
| `放装饰(obj)` / `摘装饰(obj)` | 往场景加 / 删装饰物 | `addScenery` |
| `加灯(light)` | 往场景加一盏灯 | `addLight` |
| `设环境({...})` | 改天空 / 雾 / 环境光 | `setEnv` |
| `设物理({...})` | 改重力 / 台阶 / 跳跃 | `setPhysics` |
| `改枪械(槽位, def)` | 覆盖内置枪数值（0=步枪 1=刀） | `setWeaponStats` |
| `每帧(函数)` | 每帧回调（`dt` 秒） | `addPhysicsTick` |
| `载入后(函数)` | 所有模组载入完再执行 | `onApply` |
| `清场(函数)` | **退出对局时**收掉自己放进场的东西 | `onFieldClear` |
| `广播(技能键, 数据)` | 联机广播技能事件 | `heroBroadcast` |
| `扔出(编号,x,y,z,vx,vy,vz,秒)` | 让投掷物在别人屏幕上飞 | `throwFx` |
| `切枪(idx)` / `切刀(id)` | 切换当前武器 | `selectWeapon` / `selectKnife` |
| `刷敌人(类型, x, z)` | 立刻刷一个敌人 | `spawnEnemy` |
| `取模型(名)` | 取一个具名模型的新实例 | `getModel` |
| `查出生点(x, z)` | 这个点卡不卡墙（true = 空地） | `spawnFree` |
| `刷新界面()` | 重画选人 / 选图界面 | `refresh` |
| `日志(文字)` / `警告(文字)` | 带模组名的控制台输出 | — |

**也可以把内容直接写在 `定义()` 里**（少写几行，效果一样）：

```js
枪战模组.定义({
  id: 'blade', name: '刃', ver: '1.0.0',
  hero: [英雄1, 英雄2],          // 或 hero: 单个
  weapons: [枪1, 枪2],
  knives: [刀1], throwables: [雷1],
  maps: [图1], modes: [模式1], story: [章节1],
  skills: { 技能键: 函数 },       // 等价于逐个 加技能
  enemies: { 类型名: def },
  models: { 模型名: 函数 },
  env: { fog: 0x0a1428 }, physics: { gravity: 0.01 },
  tick: function (dt) { },        // 每帧
  init: function () { },          // 载入后
  clear: function () { }          // 清场
});
```

## 5. 英雄与技能

```js
我的.加英雄({
  k: 'nightingale',              // 必填，唯一标识
  name: '夜莺', tag: '医者',      // 名字 / 定位标签（输出·突进·医者·控场…）
  fac: '暗月', facDesc: '暗月战线 · 歌声医师',
  icon: '🎵',                    // 选人界面图标（emoji）
  color: 0x9ff0d0,               // 3D 特效主色（十六进制数字）
  css: '#9ff0d0',                // 界面文字颜色
  passive: '余音绕梁：歌声持续期间移速 +12%。',
  skills: [
    { k:'song_heal', name:'治愈之歌', icon:'🎶', cd:20, dur:6, desc:'7 米内每 0.5 秒回 6 点' },
    { k:'song_calm', name:'安神谣',   icon:'🕊️', cd:12, dur:0, desc:'12 米内瞬回 25 并解减速' },
    { k:'song_lullaby', name:'安魂曲', icon:'🌙', cd:75, dur:8, desc:'大招：15 米每秒回 10' }
  ],
  sync: function (技能键, 数据, 是谁) { /* 别人放你的技能时，在他机器上复现 */ },
  remoteModel: function (模型, 信息) { /* 自定义别人看你的第三人称外观 */ }
});
```

- `cd` 冷却秒数、`dur` 持续秒数（瞬发填 0），**冷却由引擎管**，不用自己倒计时。
- 英雄下标：0~3 正规军、4 蚀日者、5 闪电、6 影月、**7+ 是模组英雄**（按加载顺序排），服务端对 7+ 一律放行，**加英雄不用改服务端**。
- `skills[].k` 写原版键（`dash` / `shield` / `boom` / `portal`…）就直接复用原版技能，只有自定义键才要 `加技能`。

**技能实现**（`k` 要和英雄 `skills` 里的 `k` 对上）：

```js
我的.加技能('song_calm', function (i, s, H) {
  // i = 第几个技能(0/1/2)，s = 技能 def（含 cd/dur/name），H = 当前英雄 def
  if (typeof showMsg === 'function') showMsg('安神谣', '#9ff0d0');
  return true;          // 返回 false 才会退回原版分支；其它值（含 true）= 我处理完了
});
```

`k` 别和原版撞车：`dash / shield / eye / boom / portal / trap / ball / mine / flash / smash / fortify / rush / adren / aura / reflect`。

## 6. 武器 / 刀 / 投掷物

### 6.1 加一把枪

```js
var 槽位 = 我的.加武器({
  name: '霰弹枪', melee: false, icon: '🔫', note: '近距离 · 一片弹丸',
  damage: 0.45,          // 伤害倍率（原版步枪 1.0 ≈ 25）
  magSize: 6, fireRate: 750, reloadTime: 2600,
  recoilMul: 1.4,        // 后坐倍率
  range: 45, pellets: 8, spread: 0.022, auto: false,
  type: 'shotgun',       // 'normal' | 'shotgun'；狙击写 scope:true
  redDot: true,          // 有红点镜（开镜自动隐藏镜身）
  magType: 'shotgun', magPos: { x: 0, y: -0.04, z: -0.02 },
  build: function (g) {
    // 只往 g 里 add。原点≈握把，-Z 朝枪口，单位米，真人比例
  },
  tpBuild: function (rig) { /* 可选：别人看你时的第三人称外形 */ }
});
我的.切枪(槽位);          // 想立刻拿在手上
```

`build` 的三条硬约定（联机时每个人的远端模型都靠它）：

1. **只往传进来的 `g` 里 `add`**，绝不能 `scene.add` / `camera.add`；
2. 原点在握把、-Z 是枪口、单位米；
3. 尽量复用材质（引擎按材质合批，每件都 `new Material` 就不合了）。

开镜相关：`type:'shotgun'` 开镜保留散射（`adsSpreadKeep: 0.35` = 保留 35%）；`scope:true` 走狙击镜（`adsFov: 18` 越小越放大）；带 `adsHide` 标记的网格开镜时自动隐藏。

### 6.2 加一把刀

```js
我的.加刀({
  id: 'claw', name: '爪刀', icon: '🗡️',
  damage: 95, range: 3.0, cooldown: 360,
  gripPos: { x: 0.20, y: -0.20, z: -0.42 },                              // 第一人称挂点
  lhPos:   { x: -0.18, y: -0.24, z: -0.30, rx: 0.5, ry: 0.8, rz: 0.3 },  // 左手位姿
  swingDur: 420,
  swing: function (o) { /* o={elapsed,total} → 返回 {rx,ry,rz,armZ,armY,done} */ },
  build: function (g) { }, tpBuild: function (rig) { }
});
```

### 6.3 加投掷物（技能掏在手上的那个东西）

```js
var 编号 = 我的.加投掷物({
  id: 'shock', name: '震荡雷', scale: 0.55,
  mesh: function () { return new THREE.Group(); }   // 每次都要新建，原点在中心，直径约 0.2 米
});
// 扔出去的瞬间，让它在别人屏幕上飞（纯视觉，伤害仍由你自己结算）
我的.扔出(编号, x, y, z, vx, vy, vz, 1.6);
```

### 6.4 改内置枪

```js
我的.改枪械(0, { damage: 2.0, fireRate: 90, magSize: 45, recoil: 0.8 });   // 0=步枪 1=战术刀
```

## 7. 地图与出生点

```js
我的.加地图({
  id: 'volcano', name: '火山据点', desc: '选图界面上的说明',
  ladder: false, tower: false,     // 有梯子 / 哨塔才写 true
  limit: 60,                       // 边界半径（米）
  build: function () {
    // 往「当前目标」里加，别自己 scene.add：
    addBox(0, 0, 0, 10, 4, 10);    // 引擎提供的建模 helper
  }
});
```

**出生点必须注册**，否则开局按经典图的 `[0,15]` 放人 —— 在你的图里可能是墙里 / 坑里 / 图外：

```js
我的.加出生点('volcano', [[0, 20], [10, 15], [-8, 18]]);   // 也可以 map 里带 spawns 字段
我的.查出生点(0, 20);                                      // true = 空地，false = 压墙
```

**想进爆能器模式**，必须连点位一起声明（缺一个就注册失败、这张图不出现）：

```js
我的.加爆能器地图('volcano', {
  sites: [{ x: -20, z: 10 }, { x: 20, z: 10 }],   // 必填：下包点 1~4 个
  spike: { x: 0, z: 34 },                          // 必填：爆能器出生点
  atk: [0, 40], def: [0, -40],                     // 可选：攻 / 守出生区
  soloSpawn: [0, 40]                               // 可选：单人训练点
});
```

点位是**客户端**加载的，进房时由**队长**报给服务端 —— 队长也得装这个模组，不然整房退回经典图坐标。要联机开局，服务端里也得有这张图的出生点（见第 10 章）。

## 8. 美术 / 物理 / 每帧 / 清场

我的.每帧(function (dt) { /* dt = 本帧秒数 */ });

我的.清场(function () {
  // 退出对局（回主菜单）时把本局加进场景的东西收掉

## 10. 联机：只有三件事

**① 服务端是白名单** —— 它不认识的 `t` 消息直接丢弃，不会帮忙转发。现成能用的：

| 消息 | 作用 | 谁发 |
|---|---|---|
| `{t:'hit', i, d, h}` | 对某个玩家造成伤害（服务端校验） | 释放者 |
| `{t:'heal', x, z, r, a, us}` | 范围治疗（满血不治、扶起倒地） | 施法者每跳发一次 |
| `{t:'grav', x, z, r, f}` | 范围引力 | 施法者（约 70ms 一次） |
| `{t:'modsk', k, d}` | 自定义技能事件，原样转发同房 | `我的.广播()` 自动发 |
| `{t:'tp'}` | **瞬移申报**：让服务器放行一次位移（见下面的坑） | 瞬移的那一刻 |

**② 技能要「本地一遍 + 广播一遍」**：

```js
我的.加技能('my_aoe', function (i, s, H) {
  冰环(camera.position.x, camera.position.z);                 // 本地特效
  我的.广播('my_aoe', { x: camera.position.x, z: camera.position.z, r: 8 });
  // 伤害只由「释放者」结算一次：打真人 netSend({t:'hit', i:目标.netId, d:35})
  return true;
});
```

别人收到 `modsk` 后，引擎会调你英雄上的 `sync(技能键, 数据, 那个玩家)` —— **sync 里只复现看得见的东西，别再扣血**（否则每个客户端各扣一遍）。

**③ 瞬移类技能必须先申报，否则会被抓回原地**

服务端有防瞬移：每个位置包最多放行 `max(3 米, 间隔 × 26 米/秒)`（间隔按 0.45 秒封顶）。
超过就不采纳，并把你拉回上一个合法位置 —— 这是为了治"网络波动导致敌人突然出现在别处"。

所以**你自己的传送 / 闪现 / 位移技能**，在改坐标之前先发一句：

```js
netSend({ t: 'tp' });          // 告诉服务器：接下来 0.8 秒内的位移是技能，不是外挂
camera.position.x = 目标x;      // 然后再瞬移
camera.position.z = 目标z;
```

只有 1.2 秒一次的频率限制，正常技能随便用。忘了发 → 玩家会看到自己"闪过去又被拽回来"。

**④ 新地图 / 新出生点要让服务端也有一份**，否则联机开局位置不对。改权威源 `服务器/服务端.js`，再用 `工具/生成多文件服务端.py` 同步。

> 自测顺序：`node --check` 过语法 → 单机看特效 → 双开浏览器同房看别人屏幕 → 再拉人。

## 11. 调试与排错

```js
node --check 你的模组.js      // 语法（先在命令行过一遍，比控制台报错好读）
```

控制台常用：

```js
枪战模组.报告()               // 每个模组到底登记了什么（英雄×1 武器×2 …）
枪战模组.表()                 // 原始数据：id / name / ver / api
ModLoader.listWeapons()       // 现有枪和槽位
ModLoader.listKnives()        // 现有刀
ModLoader.spawnFree(0, 15)    // 这个点卡不卡墙
```

| 现象 | 原因 |
|---|---|
| 英雄没出现在选人界面 | 没加进 `载入清单.js`；或在 `载入后` 之外被后面加载的模组覆盖 |
| 技能按了没反应 | 英雄 `skills[].k` 和 `加技能` 的键不一致；或函数返回了 `false` |
| 只有自己看得见 | 没 `广播`；或对方没装同一个模组 |
| 别人掉血掉两次 | 远端 `sync` 里也扣血了 —— 伤害只在释放者结算 |
| 回主菜单还留着东西 | 没写 `清场` |
| 面板里标红「接口 vX」 | 模组按更高接口写的：升级游戏，或把 `@api` 调低 |
| 装了但完全没日志 | `@api` 太高被跳过；或 `定义()` 的 `id` 和别的模组重复 |

## 12. 接口版本与兼容

| 接口版本 | 内容 |
|---|---|
| `@api 1` | 老的英文接口：`ModLoader.addHero / addWeapon / ...`（不写 `@api` 就按这个算） |
| `@api 2` | 1.7.5 起的统一接口：`window.枪战模组`，中文方法 + 元数据 + 声明式定义 |

规则：

- 模组 `@api` **高于**游戏接口版本 → 管理器标红并**不加载**（用新接口的模组在老版本上必然跑不动）；
- 低于或等于 → 正常加载（老模组不受影响）；
- 你自己的 `@ver` 随便升，只影响面板显示和发布中心的「兼容」标注。

## 13. 完整模板（复制即用）

```js
/* ============================================================================
 *  模组：寒霜法师（示例模板 —— 复制这个文件改就行）
 * 【模组信息】@id frost_mage　@name 寒霜法师　@ver 1.0.0　@api 2
 * ---------------------------------------------------------------------------
 *  V 冰环：脚下炸开冰环，6 米内敌人受 30 伤害
 *  被动：无
 * ========================================================================== */
(function () {
  'use strict';
  var M = window.枪战模组;
  if (!M) { console.warn('[寒霜法师] 需要游戏 1.7.5 或更新版本'); return; }

  var 我的 = M.定义({
    id: 'frost_mage', name: '寒霜法师', ver: '1.0.0', author: '你',
    desc: '冰系法师（模板示例）'
  });
  if (!我的) return;

  var 色 = 0x9fe8ff, CSS = '#9fe8ff';

  /* ---- 1. 特效：本地和远端共用，保证两边长得一样 ---- */
  function 冰环(x, y, z) {
    try {
      var ring = new THREE.Mesh(
        new THREE.RingGeometry(0.5, 0.62, 32),
        new THREE.MeshBasicMaterial({ color: 色, transparent: true, opacity: 0.9, side: THREE.DoubleSide, depthWrite: false })
      );
      ring.rotation.x = -Math.PI / 2;
      ring.position.set(x, (y || 0) + 0.05, z);
      ring.renderOrder = 950;
      scene.add(ring);
      var t0 = performance.now();
      (function 动画() {
        var k = (performance.now() - t0) / 600;
        if (k >= 1) { try { scene.remove(ring); } catch (e) { } return; }
        var sc = 1 + k * 7;
        ring.scale.set(sc, sc, sc);
        ring.material.opacity = 0.9 * (1 - k);
        requestAnimationFrame(动画);
      })();
    } catch (e) { }
  }

  /* ---- 2. 技能 ---- */
  我的.加技能('frost_ring', function (i, s, H) {
    var px = camera.position.x, py = camera.position.y - 1.6, pz = camera.position.z, R = 6, DMG = 30;
    冰环(px, py, pz);
    try {
      for (var n = 0; n < enemies.length; n++) {
        var e = enemies[n];
        if (!e || e.hp <= 0 || (e.isNet && e.netId === NET.id)) continue;
        var ex = e.root ? e.root.position.x : (e.x || 0);
        var ez = e.root ? e.root.position.z : (e.z || 0);
        if ((ex - px) * (ex - px) + (ez - pz) * (ez - pz) > R * R) continue;
        if (e.isNet && NET.connected) netSend({ t: 'hit', i: e.netId, d: DMG, h: false });
        else if (!e.isNet) { e.hp -= DMG; e.flash = 0.3; }
      }
    } catch (e) { }
    我的.广播('frost_ring', { x: px, y: py, z: pz, r: R });   // 别人也看得见
    return true;
  });

  /* ---- 3. 英雄 ---- */
  我的.加英雄({
    k: 'frost_mage', name: '寒霜法师', tag: '控场', fac: '', facDesc: '冰系法师',
    icon: '❄', color: 色, css: CSS,
    passive: '无（模板）',
    skills: [
      { k: 'frost_ring', name: '冰环', icon: '❄', cd: 12, dur: 0, desc: '6 米内敌人受 30 伤害' },
      { k: 'dash',       name: '闪现', icon: '💨', cd: 8,  dur: 0, desc: '直接用原版突进' },
      { k: 'shield',     name: '冰盾', icon: '🛡', cd: 30, dur: 6, desc: '直接用原版护盾' }
    ],
    sync: function (技能键, 数据) {
      if (技能键 === 'frost_ring' && 数据) 冰环(数据.x, 数据.y, 数据.z);
    }
  });

  /* ---- 4. 收尾 ---- */
  我的.清场(function () { /* 本模组没往场上留东西，不用收 */ });
  我的.载入后(function () { 我的.日志('寒霜法师已就位'); });
})();
```

## 14. 常见坑

1. **模型只往 `g` 里加**：武器 `build(g)` 的 `g` 是第一人称挂点，也是远端第三人称的挂点，往 `scene` 加会跑到世界原点。
2. **技能键对不上 = 静默失效**：英雄 `skills[].k` 与 `加技能(键)` 必须一字不差。
3. **伤害只算一次**：`sync` 里只放特效；扣血交给释放者（`netSend({t:'hit'})`）。
4. **不写 `清场` = 下一局残留**（黑洞、假人、光环、自建光源）。
5. **新图必须配出生点**，客户端 + 服务端各一份，否则人在墙里。
6. **爆能器图必须给 `sites` + `spike`**，缺一个直接注册失败。
7. **别跨分片调函数**：引擎函数可能不存在，`typeof xxx === 'function'` 判一下再调。
8. **别改 `js/` 和 `index.html`**：升级就被覆盖，写进 `mode/模组/` 才活得久。
9. **文件编码 UTF-8**；文件名用中文没问题（加载器按 URL 编码读）。
10. **`定义()` 的 `id` 要唯一**：重复会警告并复用第一个，后面登记的内容会记到别人名下。
11. **手机端一样能跑**：`mode/模组/` 会被打进 APK 的 assets，玩家也能在面板里装。
12. **发出去之前**：`node --check` → 单机跑一遍 → 双开看别人屏幕 → 再对照这一节。
